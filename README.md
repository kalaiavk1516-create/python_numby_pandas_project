# python_numby_pandas_project

📊 Python Data Analysis Project
🔹 Project Type
Python Mini Project – NumPy & Pandas Practice

🔹 Overview
This project demonstrates the use of NumPy and Pandas for handling structured data. It covers temperature analysis, student marks management, and transaction records. The goal is to practice array operations, indexing, filtering, grouping, and basic data cleaning.

🔹 Features
🧮 NumPy Arrays
Create and analyze weekly temperature data.

Convert Celsius to Fahrenheit.

Find max, min, mean values.

Slice arrays (first 3 days, middle days, weekends).

Work with 2D arrays for multiple weeks.

📑 Pandas Series
Store student marks with custom index labels.

Access values using .loc and .iloc.

Apply conditions (marks > 90).

Update values and drop entries.

Convert marks to CGPA.

📂 Pandas DataFrame (Transactions)
Create a dataset of transaction records.

Explore with .head(), .tail(), .shape, .info().

Select specific columns and rows.

Apply filters (e.g., Region = North & Amount > 200).

Perform value counts and groupby aggregation.

Update values and add new columns (Discount).

Drop rows and columns for cleanup.
